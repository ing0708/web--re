# 775 Nails — website

Single-page, mobile-responsive site for 775 Nails (NYC). Pure HTML/CSS/vanilla JS, no build step.

## Assets
Drop your files into these folders using the exact filenames referenced in `index.html`:

`images/`
- hero.jpg, about-1.jpg, about-2.jpg, process-1.jpg
- service-1.jpg, service-2.jpg
- before-after-1.jpg … before-after-4.jpg

`icons/` (Soft Taupe, use as-is)
- clock-speed.svg, check-circle.svg, shield-check.svg, trust-bundle.svg,
  leaf.svg, smiley.svg, sparkle-nail.svg, calendar.svg

Open `index.html` directly in a browser once the assets are in place.
